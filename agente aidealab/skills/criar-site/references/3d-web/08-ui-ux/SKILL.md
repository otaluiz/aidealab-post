# UI / UX

## Responsibilities
- navigation
- hero text
- CTAs
- controls
- loading state
- error state
- informational overlays
- responsive layout

## Principles
3D is an enhancement, not a barrier to the core user task.

Maintain:
- readable typography
- strong contrast
- clear hierarchy
- obvious CTA
- predictable navigation
- usable mobile layout

## Composition
Coordinate 2D and 3D using shared state or controlled props rather than tightly coupling DOM components to scene internals.
